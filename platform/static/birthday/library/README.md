# Birthday asset lifecycle

- `raw/<name>.png`: opaque RGB originals generated by ComfyUI. No alpha.
- `<name>_cut.png`: background-removed RGBA cutout. Transparent by design.
- `<name>_styled.png`: final Pantone-flat sticker with outline/shadow. RGBA, transparent outside the sticker. This is what the UI uses.
- `static/birthday/<category>.png` at the parent level are legacy fallback stickers, not raw generation originals.

The backend always prefers `_styled.png`, then `_cut.png`, then the legacy fallback.
