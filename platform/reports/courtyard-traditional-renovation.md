# 造院 · 中式传统建筑化改造报告

日期：2026-11-08
文件：`platform/projects/courtyard/web/index.html`

## 1. 改造边界

保留的核心机制：

- 一局 8 件构件；
- 构件沿列从街面向上落，落点由已有堆叠最高点决定（`landing`）；
- 矩形构件可旋转；
- 相邻房间自动开门、朝外/朝街自动开窗；
- 8 条主家委托、图结构分析、评分、宅院契、重开、音效、稀有构件；
- 成就触发与统计接口。

本次只改数值、尺寸、构件组合、评分项和视觉表达，不改落子/旋转/结算流程。

## 2. 宅基地尺度

| 项 | 旧值 | 新值 |
|---|---:|---:|
| 面阔 W | 6 格 | 10 格 |
| 进深 H | 6 格 | 8 格 |
| 长宽比 | 1:1 | 10:8（面阔大于进深） |
| 地界留白 | 紧凑 | 可形成院心天井 |

- 画面下方仍为南/街，上方为北；
- 增加中轴虚线、东/西/南/北标记；
- 院墙改为双线灰砖 + 白墙的表达；
- 单元格尺寸随屏幕宽度自适应，移动端不再溢出。

## 3. 构件尺寸

按“面阔 × 进深”计，单位仍为格：

| 构件 | 旧尺寸 | 新尺寸 | 传统依据 |
|---|---:|---:|---|
| 正房 | 3×2 | 3×2 | 三开间、两进深，全院主体量 |
| 厢房 | 2×2 | 2×3 | 三开间、两进深；两厢分列东西 |
| 书房 | 2×2 | 2×2 | 两开间小体量 |
| 净房 | 1×1 | 1×1 | 后院附属小间 |
| 厨房 | 1×1 | 2×1 | 沿院墙横向附属 |
| 门楼 | 1×1 | 1×2 | 一间两进，强调门第进深 |
| 天井 | 2×1 | 3×3 | 院心采光天井 |
| 回廊 | 1×3 | 1×3 | 沿院一侧的连续柱廊 |
| 影壁 | 1×1 | 1×1 | 门内挡景的独立短墙 |
| 月洞门 | 1×2 | 1×1 | 院墙上的圆形门洞 |
| 戏台 | 2×2 | 3×2 | 三开间戏台 |
| 太湖石 | 1×1 | 1×1 | 庭院点景 |
| 水池 | 2×1 | 2×1 | 院心水面 |

## 4. 构件组合

旧的料单是“6 件必需 + 2 件补充”；新料单改为一座**基本合院**：

```text
正房 + 东厢 + 西厢 + 书房 + 净房 + 厨房 + 门楼 + 影壁 = 8 件
```

- 两厢固定成对，形成东西围合；
- 影壁进入基本料单，门楼与影壁可以形成“门—屏”关系；
- 仍保留 8 件总数；
- 少量局会移除一件基本件，补入天井、回廊或稀有构件（月洞门/戏台/太湖石/水池），保持随机性；
- 不再把“厢房”当作单个构件随机出现。

## 5. 主家委托

| 旧委托 | 新委托 |
|---|---|
| 净房落东北角 | 正房居中，保持三开间 |
| 门楼正对街面 | 门楼正对南面街 |
| 卧室见光 | 东西两厢分列院心两侧 |
| 净房挨卧室 | 院心留出天井，不能堵死 |
| 动线短 | 影壁迎门而立 |
| 院里留空地 | 动线要短，别绕院 |
| 八件入界 | 八件都要收进宅基地 |
| 净房离正房远 | 净房避开正房和门楼 |

`analyze()` 新增格局指标：

- `layout.zhengAxis`：正房是否居中且保持三开间；
- `layout.wingsBoth`：两厢是否分列院心东西；
- `layout.huGate`：影壁是否迎门（相邻或近距离）；
- `layout.courtOpen`：院心开敞格数。

## 6. 评分

保留原评分骨架，并加入合院格局分：

- 正房居中：+8；正房存在但偏离中轴：-4；
- 两厢分列：+8；
- 影壁迎门：+4；
- 院心留空：+6；
- 原有八件入界、门楼临街、夹缝、可达性、稀有构件分继续保留；
- 总分仍限制 20–100。

## 7. 非房间要素的分类与渲染

不是所有构件都按“房间”渲染。新增 `HOUSES.kind` 分类：

| kind | 构件 | 渲染方式 |
|---|---|---|
| hall/wing/study/service | 正房/厢房/书房/净房/厨房 | 室内地面、家具、墙体、门窗、灰瓦出檐 |
| gate | 门楼 | 门楼体量、朱红大门、门钉、匾额、台阶，不画室内家具 |
| courtyard | 天井 | 室外青砖、院心树、置石，不砌墙、不画门窗 |
| corridor | 回廊 | 柱列 + 廊顶，不砌房间墙 |
| screen | 影壁 | 一段短墙 + 红心砖框，不按房间占地满铺 |
| moonGate | 月洞门 | 墙段 + 圆洞，不按房间渲染 |
| stage | 戏台 | 开放台面 + 红柱 + 屋顶，不砌墙 |
| rock | 太湖石 | 瘦皱漏透山石轮廓，不铺房间地面 |
| pond | 水池 | 水面、波纹、荷叶，不砌墙 |

门窗绘制只对 `hall/wing/study/service/gate` 执行；天井、水池、山石、影壁、月洞门、回廊不会出现门洞/窗洞。

- 动线提升到屋顶之上，避免被屋面遮挡。
